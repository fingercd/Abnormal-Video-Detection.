# 局部合并操作检验 v1（方法尚未冻结）

neutral26 的已完成 VideoMAEv2 与 TimeSformer 数据显示：在固定相邻 pair 覆盖和相同保留
数量下，两种候选分数的 high/low 选择都未优于 paired random；paired first 在 VideoMAEv2
也产生较大表示误差。因此不能把 clip 级正常—异常关联直接变成 token 的单边保留规则。
这些证据仅属于 fit 上的表示扰动诊断，不证明异常位置，也不证明检测指标的变化。

下一项最小操作是把相邻两个 patch 的 hidden state 求平均，并将它们表示为一个 token。
这是对“只取一边是否丢失了有用信息”的直接检验，不加入额外评分网络、阈值或多分支模块。
继续使用已冻结的 26 个 fit 视频、每视频两个窗口、相对深度 0.5、后缀 patch 数量减半；
与同一输入的 dense、identity 和 paired random 比较 pooled 误差。已有正反结果均保留。

几何契约：使用预先验证的真实水平相邻 pair。TimeSformer 合并完整空间轨迹，保留原 CLS；
V-JEPA2 的代表 token 采用 pair 左侧原位置作为明确 anchor，并在每个后缀层保留相同 RoPE
索引。这是近似压缩操作，不能称为原生位置完全等价；identity 单独验证原生输出一致性。

若平均操作值得继续，则训练版只增加一个每 token 共享的线性权重向量 `w[D]`：同一 pair
两边的分数经 softmax 得到加权平均。无 bias（两边共同 bias 会抵消），初始 `w=0` 等于
均值，训练与推理都使用相同加权形式。TimeSformer 的 gate 在轨迹对上共享。它只接收当前
层 hidden，未来 dense 输出仅可作为 fit 阶段离线训练目标，不能进入部署输入。

本文件仅固定操作比较与实现边界，不冻结最终插件、训练目标或论文主张。必须先看到四模型
操作回执，再判断是否采用；随后仍须完整检测质量、同预算控制、真实后缀长度、净延迟与
峰值显存验证。若不满足用户的 0.005 质量容忍度，将明确报告失败，不靠增加复杂组件补救。
