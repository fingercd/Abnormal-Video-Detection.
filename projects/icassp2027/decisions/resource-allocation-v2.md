# 本轮 GPU 调度更新：node3 八张 A100

2026-09-18，用户明确要求后续使用八张 A100，并确认八张卡都可以用于本轮任务。
后续 GPU 任务据此统一纳入 node3 的 GPU 0–7；不再把原先仅五张 A100 的占用范围当作限制。

普通特征提取、检测头训练和质量评测可以在用户授权的卡上共存运行。实现采用显式 sharing
选项、至少 16 GiB 当前可用显存、本轮每物理 GPU 一个 lease，并对本轮子进程设置最多
一半设备显存的 allocator 预算。记录真实已有 PID、显存与后续共存情况，不伪造空卡状态，
不停止既有的其他进程。默认 guard 的独占规则保持不变，只有明确指定 sharing 的本轮任务
采用此调度方式。

正式延迟和显存计时继续要求单卡独占，共卡质量运行的耗时不进入正式性能表。
已经启动的 node2 V100 作业保留并收尾，其结果不删除；后续新 GPU 任务与主要 A100
性能验证安排在 node3。node2 继续负责下载、CPU 数据准备和允许的 CPU head 工作。

本决定不改变数据成员、方法、插入层、token 预算、精度、采样、训练 epoch、head seed 或
质量容忍度。新调度是否实际使用全部八张卡，以新的进程/lease/运行回执为准。
