# 两个待确认性质，2026-09-18

已在读取独立确认集的 probe 结果之前冻结
[property-confirmation-v1.json](property-confirmation-v1.json)。它只冻结观察性质，不冻结最终插件，
不开放官方测试集。来源是完整的 128 个 fit/explore 视频，正常和正视频各64、每视频8窗口。

1. **中层 attention 分支相对更新更强。**在 VideoMAEv2 相对深度0.5（block index5），
   正视频的 attention 分支 Frobenius 范数与其即时输入范数之比较大。
   探索 g=0.921，视频分箱 bootstrap 的正负均值差0.00718，95% CI [0.00494,0.00924]。
   分母输入范数本身也有差异，分子范数单独的CI跨0；加入输入范数、运动、亮度与时长后，
   视频级标准化弱标签系数仍为0.276 [0.142,0.420]。这只是条件关联，不能称为独立异常机制。
2. **中层同坐标时间变化更小。**同一深度的 block 输入上，正视频相邻时间同坐标的
   `1-cos` 中位数较小，探索 g=-0.425；分箱视频 bootstrap 均值差-0.01081，
   95% CI [-0.01738,-0.00443]。多个类别方向相反，不能预设它会跨模型成立。

四模型只确认这些精确签名、固定方向和相对深度：12-block模型取index5，V-JEPA2取index11。
TimeSformer 的P16是 spatial attention 相对于 temporal更新后的即时输入，其他模型是联合
attention 相对于block输入；只能比较各模型内效应方向，不能直接比较这些原始比值大小。
所有统计去掉真实CLS与padding，TimeSformer的原始B×T/B×P执行batch已恢复为视频batch。

确认集固定为先前保留的64个官方训练视频，正常/正视频各32，不能替换候选。每视频8窗口，
确认推断以视频为独立单位，10000次bootstrap、seed20260918。两个方向性候选各使用单侧
alpha=.025，对应95%双侧CI的相应端点必须越过0。只有四个预定binding全部满足方向与CI条件，
并通过事先规定的运动×亮度分箱对照，才支持四encoder共同关联；单模型失败必须保留。
scene/source仍unknown，固定规则近重复审计0候选不构成完整来源隔离证明。

探索原表中的matched CI仅重抽9个分箱均值，是between-bin描述。正式条件推断使用v2：
在各bin内按正负组分别重抽视频，固定min组数权重。原表与v2均保留，不追溯改写。

无论确认结果如何，视频级性质都不自动推出token重要性。下一步最多对这两条性质做相同预算的
中立操作，比较均匀/随机保留与性质驱动操作；只有真实检测质量与净效率支持时才确定简单插件。
