## 文档综合：哪些结论进入新的当前说明

1. **研究与方法。** `docs/icassp2027/01/02/03/05/06` 和 F01–F09 文档给出正常—异常探针、模型桥、数据权限和真实缩短的门槛。F01 中层相对更新跨模型确认未通过；F02/F03 未通过独立确认；F04/P04 只支持受限的早期结构观察；F06 停止扩量；F07 的关键成员偏好臂因缓存身份 blocked；F09 的整轨迹草案运行前撤回。它们是研究历史，不应被当前目录介绍写成压缩方法已由性质充分证明。
2. **正式六格方法。** `six-cell-*` 冻结合同、`handoff_v2/audit_summary.md`、`quality_matrix.md` 与机器可读 matrix 记录三种方法、三 encoder、UCF/XD；六个 dense head 与 18 个压缩测试 run 的来源/覆盖有回执。`method_recommendation.md` 指出 PairSelect 相对两个简单对照在这六格质量上没有稳定可区分优势；该建议是在已看同一批测试数值后形成，不能把同批结果再说成独立确认。
3. **预算与效率。** 0.60 是六格主运行的保留率（TimeSformer 因轨迹粒度实际约 0.5717），0.80/0.40 属后续预算扫描。`quality_matrix.md` 中滑动 `plugin_overhead_ms` 受初始化和不同计时路径影响，不是正式效率数；应引用独立 benchmark。B1、B32、完整视频、检测头和多卡生产工时分别存放。
4. **DSANet 扩展。** `DSANET_CLIP_EXTENSION_PLAN_20260923.md` 的旧本地 full-train 后续安排被 9/23 用户要求覆盖；正式补充实验使用 UCF/XD 各一份作者发布权重。`RESULTS_PUBLISHED_20260923.md` 的八格、质量和独占效率为当前结果；batch32 视觉 encoder 有收益，但完整视频没有可信显著加速主张。原十 crop 训练特征、本地训练尝试和失败 campaign 保留，不能混入发布权重八格。
5. **数据协议。** UCF 官方 train1610/test290、原始 1-based inclusive 标注与 decoded-frame source-end reconciliation 各有合同。XD declared3954/accepted3950/excluded4、test800，raw→canonical 及作者梯形 PR-AUC 与 step AP 区分不得合并。64+64 只用于训练内筛选，正式 head 按对应 encoder×dataset 的完整训练集。
6. **稿件。** `manuscript-20260922/notes/CLAIM_EVIDENCE_MAP.md` 的 62 份证据快照和 340 条数值 provenance 是四系统稿的索引。现有 PDF、TeX、图与声明由作者另行核对；压缩包不是唯一稿件源，保留展开目录和证据快照即可。

## 文档去重与保留规则

| 类别 | 处理 | 原因 |
|---|---|---|
| 冻结 JSON、SHA 合同、论文原始回执、测试协议、负结果和正式稿件源 | 保留原件，当前页只做摘要和入口 | 它们承担实验身份、证据或作者交付，不能用摘要代替 |
| 过时的即时调度/接管说明 | 摘要并删已无独立用途的副本 | 具体 ETA/PID 已失效；真实结果与故障回执在 progress/运行目录 |
| `projects/icassp2027.zip` 源码/项目压缩包 | 已删除；先前批量命令被拦截，随后限定单一绝对路径的删除成功 | 已核 140/140 文件成员均在展开目录；其中 33 项是更早版本，当前稿件和源码以展开目录、Git/运行回执为准 |
| 论文打包 ZIP | 暂保留到投稿/交付版本逐项核对 | 用户只明确允许删源码压缩包；这些包可能是独立提交或修订交付版本 |
| 大量 `code-*` 目录 | 先绑定 run 的代码 digest，再内容去重 | 它们可能是唯一能复现旧 run 的执行源码，不等同于源码 ZIP |
