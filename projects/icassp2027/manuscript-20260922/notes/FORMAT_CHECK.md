# ICASSP 2027：版式与投稿检查

核查日期：2026-09-22。官方网页与下载示例可能存在旧日期/旧标题，按当届Paper Kit和更新更晚的投稿页分别处理，不把示例标题当作规则。

## 官方要求与本稿设置

| 项目 | 要求/本稿处理 |
|---|---|
| 页数 | 技术内容最多4页；可选第5页仅参考文献、资助致谢和伦理合规声明。没有技术附录。 |
| 页面 | Letter 8.5×11英寸；双栏；178×229mm版心，约86mm栏宽、6mm栏距。 |
| 字号 | 正文及图表说明至少9pt；本稿采用官方`spconf`的`\ninept`，未缩小页边距或改样式文件。 |
| 字体 | Times族正文、Computer Modern数学；PDF中应嵌入，避免Type3。 |
| 标题/作者 | 全大写粗体标题、实名及单位；非匿名审稿。PDF与系统作者顺序须一致。 |
| 摘要/关键词 | 约100–150词，关键词最多5个。本稿摘要135词（空白分词计数），5个关键词。 |
| 页码/文件 | 不加页码；未加密PDF，文件不超过5MB。 |
| 作者要求 | 2027要求每位作者提供有效ORCiD；单作者署名投稿数量上限为9篇。 |

## 声明与LLM政策

会议要求核对资助、利益冲突与伦理合规事项。本稿只留作者确认文字，未代写虚假的无冲突/免审批结论。
https://2027.ieeeicassp.org/about/sps-policies/

**实质性LLM起草不能仅靠披露变成合规终稿。** 当前稿件需要作者基于自己的研究实质撰写、核验并确认符合当届规则。具体说明见 `AUTHOR_HANDOFF_ZH.md`，不要原样提交。

## 本地预检不等于投稿系统验收

脚本核查页数、Letter尺寸、技术内容边界、主要字体、可疑小字号、越界文本和未解析引用。数学上下标不是普通9pt正文，不用上下标尺寸错误地判定全部论文不合格。标准模板在不同TeX安装中的实际边界可能有微小差异；检查保留测量值，而不伪称通过了会议服务器检查。

最终机器结果见 `PDF_PREFLIGHT.json`。本次还逐页检查了渲染图，修复了公式超栏、图中标签碰撞、表格输入错误、跨栏浮动体越过技术页边界、声明标题样式等问题。
